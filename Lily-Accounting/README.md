# Lily Accounting

A static personal expense tracker deployed on GitHub Pages.

- Expenses, budget settings, and theme preferences are stored only in this browser via `localStorage`.
- Analytics uses Chart.js loaded from CDN.

Based on [SiddheshJadhav1234/expense-tracker](https://github.com/SiddheshJadhav1234/expense-tracker), licensed under MIT. The original MIT license is included in `LICENSE`.
