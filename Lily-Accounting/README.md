# Lily Accounting

用于记录日常收支的中文记账网站，部署在 GitHub Pages，使用 Supabase Auth 和 PostgreSQL 管理登录、账单与个人设置。

[在线使用](https://dyorangelol.github.io/Lily-Accounting/) · [完整项目说明与部署指南](../README.md) · [更新日志](https://dyorangelol.github.io/Lily-Accounting/update-log.html)

支持收入与支出记录、备注搜索、日周月统计、支出日历、JSON 导出、六种主题，以及 40 枚自绘平面 SVG 图标。

账单和设置保存在 Supabase；浏览器中的主题缓存不是账单数据库。本地运行、Supabase 配置、数据字段及当前限制请见仓库根目录的 [README](../README.md)。
